# Ajude o Próximo — Projeto ONG

## Sobre o projeto

Site desenvolvido para uma organização não governamental com foco em ajuda humanitária. O projeto apresenta informações sobre a organização, seus projetos e um formulário de cadastro.

## Demonstração

Acesse o site publicado: **[Inserir aqui o link da Vercel]**

## Tecnologias utilizadas

* HTML5 semântico
* CSS3 e design responsivo
* JavaScript
* Vite para compilação e otimização
* IMask para máscaras nos campos do formulário
* Git e GitHub para versionamento
* Vercel para implantação

## Funcionalidades

* Navegação dinâmica em formato SPA
* Formulário com validação e máscaras
* Armazenamento local com localStorage
* Modo escuro
* Navegação por teclado e recursos de acessibilidade
* Layout responsivo para diferentes tamanhos de tela

## Como executar localmente

1. Instale o Node.js.
2. Clone o repositório:
   `git clone https://github.com/Levifreires/projeto-ong.git`
3. Entre na pasta do projeto:
   `cd projeto-ong`
4. Instale as dependências:
   `npm install`
5. Inicie o servidor de desenvolvimento:
   `npm run dev`
6. Abra no navegador o endereço informado pelo Vite.

## Compilação para produção

Execute `npm run build`. Os arquivos compilados serão gerados na pasta `dist`.

## Versionamento

O projeto utiliza Git e GitHub para controlar as alterações no código.
